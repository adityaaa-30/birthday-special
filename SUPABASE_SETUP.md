# Supabase Photo + Rating Setup

Use this when you want the opened gift photo and rating to reach Aditya.

## 1. Create Project

Create a free Supabase project at `https://supabase.com`.

## 2. Create Storage Bucket

In Supabase:

- Go to `Storage`
- Create bucket named `gift-photos`
- Make it public if you want photo links to open directly from the table

## 3. Create Table

Go to `SQL Editor` and run:

```sql
create table if not exists gift_reviews (
  id bigint generated by default as identity primary key,
  created_at timestamptz default now(),
  rating int,
  emoji text,
  photo_path text,
  photo_url text,
  user_agent text
);
```

## 4. Allow Insert From Website

For a private birthday site, the simplest setup is to enable Row Level Security and allow anonymous inserts:

```sql
alter table gift_reviews enable row level security;

create policy "allow birthday insert"
on gift_reviews
for insert
to anon
with check (true);
```

For Storage, open `Storage > Policies` and allow anon uploads to the `gift-photos` bucket.

## 5. Add Keys To Website

Open `script.js`, search `supabaseConfig`, and fill these two values:

```js
const supabaseConfig = {
  url: 'YOUR_SUPABASE_PROJECT_URL',
  anonKey: 'YOUR_SUPABASE_ANON_KEY',
  bucket: 'gift-photos',
  table: 'gift_reviews'
};
```

You can find URL and anon key in:

`Project Settings > API`

## 6. How You Will See It

After Ragini submits:

- Go to `Table Editor > gift_reviews`
- You will see rating, emoji, time, and photo path/link
- Go to `Storage > gift-photos` to see uploaded gift photos

If the bucket is public, `photo_url` can be opened directly.
